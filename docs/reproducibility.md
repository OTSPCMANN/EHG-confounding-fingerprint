# Reproducibility notes

This document expands the reproducibility note of the accompanying manuscript.

## Datasets

- **TPEHG DB** (Fele-Zorz et al., 2008) - development cohort, 300 recordings
  (38 preterm / 262 term).
- **TPEHGT DS** (Jager et al., 2018) - external validation cohort, 26 recordings
  from 18 women.

Both were collected at the same clinical centre. Download instructions and the
expected `data/` layout are in [../data/README.md](../data/README.md).

## Environment

Python 3.10.9, NumPy 2.2.6, pandas 2.3.3, scikit-learn 1.7.2, SciPy 1.15.3.
See [../requirements.txt](../requirements.txt).

## Random seeds

- **Outer cross-validation splits** (ten seeds):
  `40, 41, 42, 456, 789, 2024, 2025, 2026, 2027, 2028`.
- **Bootstrap intervals**: B = 2000 resamples, with a fixed `RandomState` per
  resampling stream - out-of-fold `42`, external set `43`, cluster `44`,
  one-per-mother `45`.

## Main configuration

The main configuration reported throughout the paper is:

```
data         results/checkpoints_lit_features_v3/lit_features_v3.csv   (189 features)
selection    direct          (no inner feature selection)
gate config  P1CI_P6eff050   (positive slot: CI test; reverse slot: EFF test, epsilon = 0.05)
classifier   rfgb            (equal-weight RandomForest + GradientBoosting)
```

`run_experiment.py` builds its configuration from environment variables and the
command line, so the main configuration requires no code changes:

```bash
# one outer seed
python src/run_experiment.py P1CI_P6eff050 42

# all ten outer seeds
bash scripts/run_10seeds.sh
```

On Windows PowerShell the ten-seed loop is:

```powershell
foreach ($s in 40,41,42,456,789,2024,2025,2026,2027,2028) {
  python src/run_experiment.py P1CI_P6eff050 $s
}
```

Each run writes to `experiments/<config>_<selection>_seed<seed>_<timestamp>/`.

## Reproducing the figure data

Figure-drawing code is not part of this release: every figure in the manuscript
was drawn manually from the exported CSV tables listed in the "Figure and table
data exports" table of [../README.md](../README.md). The scripts below regenerate
those tables.

```bash
python analysis/pipe05_ci.py            # record-level bootstrap intervals
python analysis/_summarize_runs.py      # per-configuration run summary
python analysis/_summarize_cl.py        # classifier-family summary
python analysis/_r41_fingerprint.py     # fingerprint table
python analysis/_r42_uncertainty.py     # ROC and uncertainty exports
python analysis/_r44_insample.py        # reference-scale levels
python analysis/_r45_dims.py            # D2-D4 exports
```

## Interpreting the OOF reporting convention

Development-set AUCs are reported **out-of-fold (OOF)**: the ten-fold pooled OOF
predictions for the arguments over all seeds. External-cohort AUCs are the mean
over the ten per-fold test predictions. No fold-mean values are reported.
